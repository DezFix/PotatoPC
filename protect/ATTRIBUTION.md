# Сигнатуры YARA

29 правил из открытого репозитория [Yara-Rules/rules](https://github.com/Yara-Rules/rules)
(лицензия — см. LICENSE в их репозитории, свободная open-source).
Отобраны вручную под домашние угрозы: стилеры, RAT, майнеры, шифровальщики,
банкиры, кейлоггеры, загрузчики. Без `include` — склеиваются в один файл.

Файлы без изменений, кроме:
- RAT_DarkComet.yar: `.+` -> `.{1,128}` (убирает ворнинг YARA, детект тот же);
- GEN_PowerShell.yar УДАЛЁН: дженерик-правило давало ложняки на легитимных
  Electron-архивах (app.asar). Проверка PowerShell-угроз остаётся за Defender.
Обновление — вручную свежими копиями.

Движок YARA в репозиторий НЕ кладём: скачивается при первом скане
с официальных релизов VirusTotal/yara (BSD-3), сейчас pinned v4.5.5:
yara-4.5.5-2368-win64.zip
