# PotatoPC

## Установка

### 1. Безопасно (со сверкой SHA256) — рекомендуемый способ
```powershell
Invoke-WebRequest https://raw.githubusercontent.com/DezFix/PotatoPC/main/Install-PotatoPC.ps1 -OutFile Install-PotatoPC.ps1
# Аудит без запуска: скачать архив, показать хэш, проверить все файлы
.\Install-PotatoPC.ps1 -VerifyOnly
# Запуск со сверкой хэша ZIP-архива релиза (хэш — на странице Releases)
.\Install-PotatoPC.ps1 -ExpectedHash '<SHA256_ZIP_АРХИВА>'
```
Несовпадение хэша = архив удаляется, запуск блокируется. Установочный каталог по умолчанию защищён в `C:\ProgramData\PotatoPC\install`, поэтому запускай PowerShell от имени администратора. Хэш `menu.ps1` находится в `SHA256SUMS`, но для `-ExpectedHash` нужен отдельный SHA256 ZIP-архива.

### 2. Локально из клона
```powershell
powershell -STA -NoProfile -ExecutionPolicy Bypass -File menu.ps1
```
Работает без сети. Исходники открыты: можно прочитать перед запуском.

### 3. Быстро (шортлинк) — без сверки, на свой страх и риск
```powershell
irm "https://kutt.to/potatopc" | iex
```
⚠️ **Код выполняется сразу от имени администратора, без проверки хэша, а шортлинк
непрозрачен.** Скрипт сам поднимает PowerShell с правами админа
(`Start-Process -Verb RunAs`), то есть выполняется в привилегированном
контексте. Пользуйся только если доверяешь владельцу репозитория. Шортлинк
ведёт на `menu.ps1` в ветке `main`; чуть прозрачнее — тот же конечный URL:
```powershell
irm https://raw.githubusercontent.com/DezFix/PotatoPC/main/menu.ps1 | iex
```

Замечание про SmartScreen/Defender: ругаться будет на любой запуск
скрипта, скачанного из интернета — это нормально. Исходники открыты: скачай,
прочитай, потом запускай. После сверки хэша bootstrap сам снимает
блокировку (`Unblock-File`) с проверенного архива.

### 4. Интерфейс v6 (по умолчанию)
```powershell
powershell -STA -NoProfile -ExecutionPolicy Bypass -File menu.ps1
```
Дашборд, закреплённые панели действий, кастомный хром.

Описание шапки сприптов 
```powershell
﻿# NAME: Название
# DESC: Описание 
# TAGS: 1,2,3,win11 (1-безопасно 2-осторожно 3-опасно win11-то что работает только на windows11)
# ICON: Емодзи брать на сайте https://emojidb.org/
# PRESET: potato,office,game (в какие пресеты входит: potato-слабый ПК, office-работа, game-игры)
```

Нумерация скриптов: файлы лежат как `scripts/02 Очистка/04_remove_bloat.ps1`,
номер раздела + номер файла (`02 04`) виден и в интерфейсе. Откаты вынесены
в отдельный раздел «Откаты» и не показываются в общем списке модулей.
Порядок в разделе — по номеру файла. Поиск скрывает разделы без совпадений;
зависший скрипт получает до двух попыток, затем скипается, очередь идёт дальше.
Если стоит галка перезагрузки, перезагрузка выполняется только после явного
подтверждения списка скриптов.

## Пресеты

Пресет — это набор галочек «в один клик». В них входят **только пункты,
реально влияющие на скорость, память, диск и автозагрузку**. Косметика
(тёмная тема, расширения файлов, классическое меню), приватность и
диагностика остаются отдельными кнопками — их эффект на «ПК тормозит» равен
нулю, а в пресете они только мешают понять, что именно помогло.

Скрипт вступает в пресет строкой `# PRESET: potato,office,game` в шапке.
Пустая строка `# PRESET:` = только ручной запуск.

## Очистка — необратима

Пункт «Очистка» удаляет файлы **навсегда, минуя корзину**. Поэтому:
- перед чисткой запрашивается подтверждение, а пункты-кэши разработчика
  (npm, pip, NuGet) перечисляются в диалоге отдельным списком;
- после чистки в лог пишется, **что именно удалено** (сколько файлов и
  сколько байт), а список первых 200 путей складывается в
  `%TEMP%\PotatoPC\clean-logs\removed-<метка>.log`;
- точки восстановления система создаётся автоматически, если она включена.
