# PotatoPC v7

Ускорение, очистка, защита и проверка Windows 10/11, в первую очередь для слабых ПК.

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Главная** | Сводка о железе, оценка системы 0–100 по скорости, чистоте, приватности и безопасности, список проблем с переходом к исправлению, кнопка «Оптимизировать» |
| **Твики** | Плагины из `scripts\`: поиск, разделы, пресеты (Слабый ПК / Офис / Игры), статус «применено», откат раздела |
| **Очистка** | Temp, кэши браузеров, игр и программ, корзина, шейдеры. Защита пользовательских папок, отчёт об удалённом |
| **Реестр** | Не «чистка» ради цифр: вирусные блокировки (диспетчер задач, IFEO, Winlogon, Защитник), автозагрузка и задачи в никуда, битые пункты меню, ассоциации и App Paths. Копия перед изменением, откат из «Истории» |
| **Автозагрузка** | Программы, задачи и службы, оценка влияния, «Выключить рекомендованные», время загрузки Windows |
| **Программы** | Установка наборами и по одной, поиск, обновления (через winget). Если winget нет — ставит его сам |
| **Удаление программ** | Все программы и приложения Store: размер, дата, пакетное и тихое удаление, поиск остатков (папки, реестр, ярлыки) с удалением в Корзину |
| **Драйверы** | Подписанные драйверы из Microsoft Update, устройства с ошибками, резервная копия и восстановление драйверов |
| **Сеть** | Замер скорости (Cloudflare), диагностика по шагам с вердиктом и кнопкой исправления, сброс DNS/прокси/hosts/Winsock, безопасный DNS, адаптеры, пароли сохранённых Wi-Fi, соединения программ, трассировка |
| **Пользователи** | Создание и удаление учётных записей, пароли, права администратора, автовход, гость. Файлы пользователя на другом диске (D:): переживают переустановку Windows, а после неё возвращаются новой учётке вместе с данными браузеров и программ. Работает и в Windows Home |
| **Защита** | Защитник Windows (проверки, базы), настройки безопасности, угон браузера (поисковик, расширения, политики, прокси) |
| **Обслуживание** | Починка Windows (DISM+SFC, диск, сеть, Центр обновления, кэш значков, Store), автообслуживание по расписанию, портативный режим |
| **Тест ПК** | Режим мастера: процессор, нагрев, память, диск (скорость и SMART), батарея, видео. Оценка, рекомендации, HTML-отчёт для клиента |
| **История и откаты** | Журнал действий, откаты по разделам, точки восстановления |

## Запуск

```powershell
# по ссылке
irm https://raw.githubusercontent.com/DezFix/PotatoPC/main/menu.ps1 | iex

# из папки
powershell -STA -NoProfile -ExecutionPolicy Bypass -File menu.ps1

# со сверкой SHA256 архива релиза
.\Install-PotatoPC.ps1 -ExpectedHash '<SHA256_ZIP>'
```

Нужны права администратора: если их нет, программа перезапустится сама. По ссылке скачивается архив ветки `main`, и перед запуском каждый файл сверяется с `SHA256SUMS`.

**Портативный режим.** Положите рядом с `menu.ps1` файл `portable.txt` (или нажмите кнопку на странице «Обслуживание»). Тогда журнал, история и отчёты хранятся в `data\` рядом с программой. Удобно для флешки мастера.

## Свои плагины

Положите `.ps1` с шапкой в `scripts\<NN Раздел>\` — он появится на странице «Твики». Вкладку можно добавить так же: файл в `pages\`. Подробности и примеры — в [docs/PLUGINS.md](docs/PLUGINS.md).

## Структура

```
menu.ps1            точка входа: права, загрузка, окно
core\               ядро: настройки, фоновые задачи, плагины, система, winget, интерфейс
pages\              вкладки (каждая - плагин)
scripts\            твики (плагины)
cleaner\            движок очистки и правила
assets\             тема, окно, тесты производительности (C#)
tools\              генерация SHA256SUMS для релиза (в архив по ссылке не входит)
tests\              тесты Pester (в архив по ссылке не входит)
```

## Для разработчика

* Перед коммитом пересоберите манифест: `tools\New-ReleaseHashes.ps1`.
* Тесты: `Invoke-Pester .\tests` (Pester 5).
* Все `.ps1` хранятся в UTF-8 с BOM.
* Опорные значения «Теста ПК» (100 = средний новый ноутбук 2025 года) лежат в `Get-TestReference`. Их можно переопределить файлом `assets\test-reference.json`, например `{ "CpuSingle": 300000000 }`.
