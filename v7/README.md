# PotatoPC v7

Новая модульная версия. Старая версия осталась в корне репозитория и в ветке
`backup/pre-rewrite-*`; она не тронута.

## Что уже работает

- GUI: `v7\PotatoPC.cmd` — три большие кнопки, safe/full, план, журнал, откат.
- Кнопка «Проверить»: dry-run без изменений, показывает полный вывод в журнале.
- Три профиля: `potato`, `office`, `game`.
- Режимы `safe` (по умолчанию) и `full` (добавляет осторожные пункты).
- `-DryRun`: показать план и ничего не менять.
- `-List`: показать профили и все действия.
- `-ExportPlan`: сохранить план в JSON.
- Сессия: план, система, результаты каждого действия, лог.
- Откат по сессии: `-Undo -Session <id>`.
- Точка восстановления перед изменениями (можно отключить `-NoRestorePoint`).
- Проверка путей: действие не может выйти за пределы `v7`.
- Тесты: 20/20.

## Быстрый старт

Для обычного пользователя: двойной клик по `v7\PotatoPC.cmd`. Появится UAC,
дальше — три кнопки и кнопка «Применить».

Для просмотра без прав администратора:

```powershell
powershell -STA -NoProfile -ExecutionPolicy Bypass -File .\v7\gui\Start-PotatoPC.ps1 -Preview
```

CLI:

```powershell
# посмотреть, что есть
.\v7\PotatoPC.ps1 -List

# показать план для слабого ПК, ничего не менять
.\v7\PotatoPC.ps1 -Profile potato -DryRun

# применить safe-профиль (clean-junk необратим, поэтому нужно явное разрешение)
.\v7\PotatoPC.ps1 -Profile office -Yes -AllowIrreversible

# применить full-профиль (добавляет осторожные пункты)
.\v7\PotatoPC.ps1 -Profile game -Full -Yes

# сохранить план
.\v7\PotatoPC.ps1 -Profile potato -Full -ExportPlan .\potato-plan.json

# откатить последнюю сессию
.\v7\PotatoPC.ps1 -Undo

# откатить конкретную сессию
.\v7\PotatoPC.ps1 -Undo -Session 20261109-154400-123
```

Для применения нужны права администратора. `-DryRun` и `-List` работают без них.

## Если что-то пошло не так

- Журнал сессии: `%TEMP%\PotatoPC\logs\session-*.log` или
  `%ProgramData%\PotatoPC\logs\` при запуске от администратора.
- Сессии: `%TEMP%\PotatoPC\sessions\*.json`.
- Падение интерфейса: `%TEMP%\PotatoPC\gui-crash.log`.
- Кнопка «Проверить» делает dry-run: план строится, ничего не меняется.

## Безопасность

- `safe` не содержит пунктов с `risk: caution/advanced`.
- `clean-junk` в safe-режиме не трогает игры/шейдеры и кэши с флагом
  `Confirm` (npm/pip/NuGet).
- `-Yes` не перезагружает компьютер сам по себе: перезагрузка только после
  отдельного подтверждения или `-Reboot`.
- Если в плане есть необратимое действие, `-Yes` требует
  `-AllowIrreversible`. Случайно снести кэши в unattended-режиме нельзя.
- Точка восстановления создаётся до первого изменения.
- Каждая сессия пишет лог и JSON; откат идёт по сессии.
- Действия помечены `irreversible`, если откат невозможен.
