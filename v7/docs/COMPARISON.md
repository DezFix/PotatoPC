# Сравнение с популярными open-source проектами

Смотрел: WinUtil (Chris Titus), Sophia Script, Win11Debloat, Optimizer
(hellzerg), ThisIsWin11, WPD (Windows Privacy Dashboard).

| Проект | Сильно | Слабо / что не берём |
|---|---|---|
| **WinUtil** | JSON-конфиги для приложений, твиков, фич и пресетов; headless `-Preset`; импорт/экспорт конфига; undo-состояние; отдельные UI/worker runspace; очередь задач; логи; Pester | Очень большой охват, UI перегружен; часть твиков спорная; нам не нужен ISO-билдер |
| **Sophia Script** | 150+ функций; у каждого твика есть restore-функция; официальные документированные методы; проверки стабильности; локализация; подпись релизов; winget/scoop/choco; PowerShell 7 и ARM64 | Это библиотека функций, а не «нажал и ушёл»; нет трёх профилей |
| **Win11Debloat** | CLI; audit/sysprep-режим; применение к другому пользователю; экспорт/импорт настроек; откат; динамический список UWP; лёгкий запуск без установки | Нет нормального GUI; профили не про «слабый/офис/игры» |
| **Optimizer** | Портативный; 24 языка; шаблоны и silent-run; бэкапы; hosts/DNS/startup/UWP; инспекция железа | Отключает Defender (мы этого не делаем); часть функций опасна для обычного пользователя |
| **ThisIsWin11** | Модульные компоненты; пакеты через winget; автоматизация PowerShell; расширения | Только Windows 11; меньше фокуса на безопасности и откате |
| **WPD** | Приватность, firewall-правила, портативность | Узкая специализация; нет оптимизации и профилей |

## Что у PotatoPC уже хорошо

- Три понятных профиля: potato / office / game. Ни у одного конкурента нет
  такой же простой модели «выбери класс ПК».
- Защита очистки: `CleanGuard`, запрет обхода reparse point, защита своих папок.
- SHA256-манифест и установщик с проверкой архива.
- Тесты на AST, JSON, манифест, Defender, очистку.
- Откаты по разделам.
- Русский язык и ориентация на системного администратора.
- Не ослабляет Defender и не выключает firewall.

## Что берём в v7

- Из WinUtil: конфиг-файлы, явные пресеты, dry-run/headless, сессии, логи.
- Из Sophia: курс на restore-функции и проверки стабильности; локализация.
- Из Win11Debloat: CLI, audit/sysprep, экспорт/импорт, откат.
- Из Optimizer: шаблоны/silent-run, но без отключения Defender.
- Из ThisIsWin11: модульность и пакеты приложений.
- Из WPD: аккуратная приватность, но не как отдельный продукт.

## Что сознательно не делаем

- Не отключаем Defender и не добавляем exclusions.
- Не блокируем драйверы Windows Update в профилях.
- Не кладём косметику в safe-профили.
- Не запускаем необратимую чистку без подтверждения.
- Не делаем «1000 твиков»: только то, что реально влияет на скорость,
  память, диск, автозагрузку и приватность.
