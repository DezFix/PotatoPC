# Источники путей очистки
Часть путей взята из открытых правил [Kudu](https://github.com/AdventDevInc/kudu)
(`rules/win32/*.json`, MIT License, (c) AdventDevInc) и переработана:
русские названия, курированный безопасный набор, наш формат.

Сознательно НЕ чистим (в отличие от Kudu):
- Prefetch — ускоряет запуск, чистка вредит;
- Windows.old — нужна для отката системы;
- Minidump — нужны нашей же диагностике BSOD;
- Installer $PatchCache$ — ломает удаление программ;
- WinSxS — только через DISM, не файлами;
- Журналы событий (.evtx) — нужны диагностике;
- Данные Defender — не трогаем антивирус;
- Сессии и пароли (Telegram tdata, браузерные пароли/куки) — только кэши.
